# zad-food-rescue
**زاد (Zad) — حفظ النعمة وإنقاذ الطعام** تطبيق لربط فائض الطعام النظيف من المطاعم والمخابز والمنازل بالمستفيدين القريبين عبر الخريطة وتحديد المسار (GPS)، مع نظام استلام صامت برمز (QR) يحفظ كرامة المستلم، وإمكانية نشر الفائض بسهولة. *تم التصميم والبرمجة من قبل المهندس سلام الأعرجي.*
