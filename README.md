# خارطة التطوير المستقبلي ودليل النشر - تطبيق زاد (Zad)
**تم التصميم والبرمجة من قبل المهندس سلام الأعرجي**

## 1. البنية البرمجية القابلة للتطوير (Modular Architecture)
تم فصل التطبيق إلى طبقات مستقلة لتسهيل إضافة ميزات جديدة مستقبلاً دون تعديل الواجهات:
- `lib/core/app_config.dart`: إدارة المفاتيح السحابية وإعدادات التطبيق المركزية.
- `lib/services/surplus_repository.dart`: طبقة البيانات؛ تعمل محلياً للتجربة الفورية، وتتحول تلقائياً إلى المزامنة السحابية الحية بمجرد إضافة مفاتيح `Supabase`.
- `lib/data/iraq_regions.dart`: قاعدة بيانات التقسيمات الإدارية (المحافظة ← القضاء ← الناحية ← الحي/القرية) والآيات القرآنية وأقوال أهل البيت (عليهم السلام).

## 2. ميزات مقترحة للإصدارات القادمة (v2.0+)
- **توثيق الحسابات عبر OTP**: تسجيل الدخول برقم الهاتف العراقي للجمعيات الخيرية والمتبرعين.
- **الإشعارات الفورية (Push Notifications)**: تنبيه المستلمين القريبين فور نشر طعام زائد في نفس الحي.
- **قارئ كاميرا مدمج للكاشير**: لمسح رمز QR الخاص بالمستلم الصامت مباشرة من التطبيق.
